# ADR-001: Arquitectura vanilla ES Modules sin build step

## Status
Accepted

## Date
2026-10-20

## Context
Necesitamos una calculadora de notas para el semestre 2026-2 de Psicología PUCP. Requisitos:
- Funcionar en GitHub Pages (hosting estático gratuito)
- Cero configuración de despliegue
- Fácil de mantener y entender
- Sin dependencias de runtime pesadas
- Accesible y performante

## Decision
Usar **vanilla JavaScript con ES Modules nativos** sin bundler (Vite, Webpack), sin framework (React, Vue), sin build step.

Estructura:
- `index.html` + `<script type="module" src="app.js">`
- `data.js`, `calculations.js`, `app.js` como ES Modules
- `styles.css` con custom properties (design tokens)
- Tests con Vitest (solo para desarrollo, no se bundlean)

## Alternatives Considered

### Vite + React/Vue
- **Pros:** DX moderna, HMR, ecosistema, tree-shaking
- **Contras:** Build step obligatorio, config extra, sobreingeniería para 4 archivos JS, GitHub Pages necesita `gh-pages` branch o GitHub Actions

### Single HTML file con todo inline
- **Pros:** Un archivo, cero config
- **Contras:** Inmantenible, sin separation of concerns, difícil testear, sin syntax highlighting en editor

### Web Components (Lit, vanilla)
- **Pros:** Encapsulamiento nativo, reutilizable
- **Contras:** Verboso para esta escala, Shadow DOM complica CSS global/design tokens

## Consequences

### Positivas
- **Deploy trivial:** `git push` → GitHub Pages sirve directo
- **Cero dependencias runtime:** 0 KB JS framework, solo ~5 KB código propio
- **Tests aislados:** `calculations.js` es 100% pura y testeable sin DOM
- **Debugging nativo:** Stack traces claros, sourcemaps innecesarios
- **Longevidad:** ES Modules estándar web, no depende de tools que caducan
- **Performance:** Sin hydration, sin virtual DOM, paint inmediato

### Negativas
- **Sin HMR:** Recarga manual (mitigado con `npx serve` + live reload nativo del navegador)
- **Sin TypeScript:** Usamos JSDoc en su lugar (ver `calculations.js`)
- **Sin tree-shaking automático:** Código tan pequeño que no importa
- **Import maps no usados:** Rutas relativas simples (`./data.js`)

## Implementation Notes
- `type: "module"` en `package.json` para Node tests
- `defer` implícito en `type="module"`
- Custom properties CSS para theming futuro (dark mode)
- Delegación de eventos en `app.js` (un listener global para `.meta-input`)
